## 🛠️ Tech Stack & Architecture

- **Runtime**: Node.js
- **Architecture**: Modular Services & Controllers
- **Testing**: Automated Unit Test Suites (`tests/`)
- **Automation**: GitStreak AI Daily GitHub Actions (4 Commits / Day at 4:00 PM IST)
